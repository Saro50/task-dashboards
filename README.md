# AICodeAgent 任务分期看板

项目价值：希望用同一套短工作流情景，套用于大部份生成，不考虑协作。
 - 帮助用户梳理并完成能并行执行的任务
 - 用 `worktree` 隔离每一项任务，完成基本提交合并流程。

## 基础概念：
1. 项目，达成目的的聚类行为概念。
2. worktree,隔离的工作区。
3. 任务：实施规划的最小单元。

## 关键业务模块

# 项目创建：
> 模块用途: 快速初始化项目并输出项目简介文件
操作流程：
    - 指定目录
    - 设置项目名称，描述
    - 创建，初始化一个git仓库，并根据"描述，项目名称"扩写填入生成项目第一个"README.md"文件。

功能拆分：
| 功能 | 说明 |
|------|------|
| 目录选择 | 指定项目创建的目标目录路径 |
| 项目信息录入 | 设置项目名称、描述等基本信息 |
| Git 仓库初始化 | 在目标目录中初始化 Git 仓库 |
| README 生成 | 基于项目名称和描述，由 AI 扩写生成初始 README.md |

# AI讨论聊天窗：
> 模块用途：与AI讨论推进执行的窗口，并输出待执行任务，讨论聊天窗口，与AI互动的主要交互区域。
操作流程：
    - 通过[AI任务实施引擎](#AI任务实施引擎：) 提供 AI 能力
    - 划区或选取指定内容，也可以不选取，手动输入。
    - 总结任务主题。
    - 创建并给出任务实施步骤依赖路线。

功能拆分：
| 功能 | 说明 |
|------|------|
| AI 对话交互 | 与 AI 进行多轮对话，讨论任务细节 |
| 内容选取 | 支持划区或选取指定内容作为讨论上下文 |
| 手动输入 | 支持用户手动输入指令或需求描述 |
| 任务主题总结 | AI 自动总结讨论中的任务主题 |
| 任务步骤路线生成 | AI 创建并输出任务实施步骤及依赖关系 |

# 任务呈现：
> 模块用途：呈现AI讨论聊天窗口输出的，任务步骤实施路线图谱，可以人为调整或者补充
操作流程：
    - 查看任务/步骤实施图谱
    - 编辑任务/步骤实施内容
    - 呈现任务当前实施状态

功能拆分：
| 功能 | 说明 |
|------|------|
| 任务图谱展示 | 以图谱形式呈现任务/步骤的实施路线 |
| 任务编辑 | 支持人为编辑、调整任务/步骤的内容 |
| 任务状态追踪 | 实时展示每个任务/步骤的当前实施状态 |

# AI任务实施引擎：
> 模块用途：配置，管理Agent，记录 worktree 管理完成提交流程等，保障任务实施可靠性，用户不可直接操作

功能拆分：
| 功能 | 说明 |
|------|------|
| Agent 配置管理 | 配置和管理 AI Agent 的参数与行为 |
| Worktree 管理 | 通过 Git Worktree 隔离各任务的工作区 |
| 任务执行调度 | 按依赖关系调度和执行任务步骤 |
| 提交流程管理 | 管理任务的提交、合并流程 |
| 执行可靠性保障 | 记录日志、异常处理，保障任务实施过程可靠 |
